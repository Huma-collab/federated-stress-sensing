
# Privacy-Preserving Federated Learning for Longitudinal Smartphone Behavioural Sensing

Code, training logs, and figures supporting the paper *"Privacy-Preserving
Federated Learning for Longitudinal Smartphone Behavioural Sensing: A
Multi-Channel LSTM Approach to Stress Monitoring."*

## What's Included vs. Excluded

**Included:** the verified code paths that produced every reported number in
the paper, condensed log summaries (per-round accuracy/weighted-F1, extracted
from the full training output), and all figures referenced in the manuscript.

**Not included:**

- **Raw dataset.** The College Experience Study dataset is publicly available
  on PhysioNet under a data use agreement:
  https://physionet.org/content/globem/. It is not redistributed here.
- **Trained model checkpoints.** Per-client weight files (~1 GB across all
  configurations) are not included; they can be regenerated by running the
  training scripts against the dataset above. [Optional: add a Zenodo DOI
  here if checkpoints are archived separately.]
- **Exploratory/superseded scripts.** Several intermediate scripts used
  during development (alternative feature-extraction pipelines, abandoned
  model variants) are excluded in favour of the verified pipeline above.

## Reproducing the Results

1. Obtain the College Experience Study dataset from PhysioNet and place it
   per the path expected in `code/config/settings.py`.
2. Install dependencies (Python 3.10, PyTorch 2.6, Flower 1.27.0; see paper
   Methodology for full environment details).
3. Run `code/main.py` for the federated result, `code/local_baseline.py` for
   the local-only baseline, `code/src/central.py` for the centralised
   baseline, and `code/all_classifiers_v1.py` for the classical ML
   comparison.
